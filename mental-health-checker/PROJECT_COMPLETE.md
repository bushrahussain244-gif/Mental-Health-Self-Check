## 📞 Support & Help

### Troubleshooting Approach:
1. Check QUICKSTART.md
2. Check WINDOWS_SETUP.md (if Windows user)
3. Review browser console (F12)
4. Check server terminal output
5. Clear browser cache
6. Restart server
7. Restart computer (Last resort)

### Common Fixes:
```bash
# Port already in use
netstat -ano | findstr :3000
taskkill /PID [PID] /F

# Dependencies not installed
npm install

# Cache issues
npm cache clean --force
npm install

# Server not starting
# Check: Is backend/server.js in correct location?
# Check: Have you run 'npm install'?
# Check: Is Node.js installed? (node --version)
```
